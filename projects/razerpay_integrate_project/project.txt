Create a modern, responsive, production-ready **clothing e-commerce website** for an Indian clothing brand with **Razorpay payment gateway integration**.

## 1. Website Goal

Build a professional online clothing store where customers can:

- Browse clothing products
- Search and filter products
- View product details
- Select size and color
- Add products to cart
- Apply coupons
- Enter delivery address
- Place orders
- Pay securely using Razorpay
- View order confirmation
- Track their orders

The website should look like a premium modern fashion store similar to leading Indian e-commerce websites.

# 12. Razorpay Integration

Implement the complete Razorpay payment flow.

### Backend flow

When the user clicks:

**Pay Now**

Frontend calls:

```http
POST /api/payment/create-order
```

Backend creates a Razorpay order using:

```javascript
razorpay.orders.create({
    amount: amountInPaise,
    currency: "INR",
    receipt: receiptId
});
```

Return the Razorpay order ID to frontend.

---

# 13. Razorpay Checkout

Frontend should open Razorpay Checkout using:

```javascript
const options = {
    key: RAZORPAY_KEY_ID,
    amount: order.amount,
    currency: "INR",
    name: "STYLEHUB",
    description: "Fashion Order",
    order_id: order.id,

    handler: async function (response) {
        // Send payment details to backend
        // Verify Razorpay signature
    },

    prefill: {
        name: customer.name,
        email: customer.email,
        contact: customer.phone
    },

    theme: {
        color: "#111111"
    }
};
```

Use Razorpay's official checkout script.

# 14. Payment Verification

IMPORTANT:

Never trust payment success information directly from the frontend.

After payment, send:

```http
POST /api/payment/verify
```

with:

```json
{
    "razorpay_order_id": "...",
    "razorpay_payment_id": "...",
    "razorpay_signature": "..."
}
```

Backend must verify the Razorpay signature using the Razorpay secret.

Use HMAC SHA256 signature verification.

Only after successful verification:

1. Mark payment as successful
2. Mark order as confirmed
3. Store payment ID
4. Store Razorpay order ID
5. Reduce product inventory
6. Clear user's cart
7. Generate order confirmation

# 22. Security Requirements

Implement production-grade security.

- Never expose Razorpay secret
- Validate all API inputs
- Validate product prices on backend
- Never trust price sent from frontend
- Verify Razorpay signatures
- Use HTTPS in production
- Use JWT securely
- Add rate limiting
- Add CORS configuration
- Sanitize user inputs
- Protect admin routes
- Use environment variables
- Prevent duplicate payments/orders
- Use server-side inventory validation

IMPORTANT:

The final order amount must always be calculated on the backend from database product prices.

Do not accept the final payment amount directly from the frontend.

# 29. Razorpay Webhook

Also implement Razorpay webhook support for reliable payment status synchronization.

Create:

```http

```

Handle relevant events such as:

```text
payment.captured
payment.failed
order.paid
```

Verify the webhook signature before processing events.

Make webhook processing idempotent so duplicate webhook events do not create duplicate orders or payment records.
